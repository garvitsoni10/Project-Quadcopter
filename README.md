# Project-Quadcopter
Design, build, programming, and testing of a custom F450 quadcopter using an ESP32.

A personal engineering project documenting the design, construction, programming, and testing of an quadcopter using an ESP32-based flight controller, essentially designing a drone.

<h2> Project Goals </h2>

Learn and apply mechanical CAD <br>
Understand quadcopter hardware and electronics<br>
Develop an ESP32-based flight-control system<br>
Assemble and test the drone<br>
Document the engineering process, problems, and design iterations

<h2> Hardware </h2>

Frame <br>
Brushless motors<br>
ESCs<br>
Propellers<br>
ESP32<br>
Gyroscope <br>
and power electronics<br>
